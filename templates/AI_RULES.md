## Stack

| Concern    | Choice                                              | Notes                                   |
| ---------- | --------------------------------------------------- | --------------------------------------- |
| Framework  | TanStack Start (React, file-based routes)           | `src/routes/`, `routeTree.gen.ts` is generated |

## Directory Conventions

- `src/routes/` — one file per route, `createFileRoute`, `validateSearch` for URL state
- `src/components/ui/` — shadcn primitives only, no business logic
- `src/components/<feature>/` — feature components, under 200 lines each
- `src/server/` — `createServerFn` handlers, `db/`, `auth.ts`, `env.ts`
- `supabase/` — migrations, rollbacks, seed, functions
- `design/` — manifest and decisions for the Claude Design round trip

## Rules

1. URL state over `useState` for anything a user would bookmark or share.
2. Browser-only APIs live inside `useEffect` or `clientOnly`.
3. Secrets and database clients are reached only through `src/server/*.server.ts`.
4. Every private `createServerFn` has `.middleware([requireRole(...)])` and `.validator(zod)`; `beforeLoad` is UX only.
5. Roles come from `memberships`, never from `user_metadata`.
6. Every table has `tenant_id`, explicit grants and four RLS policies `to authenticated` using `(select auth.uid())`.
7. Views use `security_invoker = true`; `security definer` functions set `search_path` and revoke `anon`.
8. Every structural migration has a snapshot and a rollback file.
9. Every turn ends with `npx tsc --noEmit` exit `0`, the security scan, and before deploy `wrangler deploy --dry-run`.
10. Deploy lab first, smoke-check with seeded test accounts, then production. Never with uncommitted changes.
