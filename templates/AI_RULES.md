## Stack

| Concern    | Choice                                              | Notes                                   |
| ---------- | --------------------------------------------------- | --------------------------------------- |
| Framework  | TanStack Start (React, file-based routes)           | `src/routes/`, `routeTree.gen.ts` is generated |
| Build      | Vite + `@cloudflare/vite-plugin`                    | dev-only source tagger in `tooling/`    |
| Runtime    | Cloudflare Workers (`wrangler.jsonc`)               | `nodejs_compat`, assets binding         |
| Data       | Supabase Postgres + Auth + Storage                  | RLS on every table                      |
| Validation | Zod                                                 | search params, server fn inputs         |
| UI         | shadcn/ui in `src/components/ui/*`, lucide-react    | semantic tokens in `src/styles/app.css` |
| Styling    | Tailwind with CSS variables                         | no raw hex or px in components          |
| Tests      | Vitest (unit), Playwright (smoke on preview URL)    |                                         |

## Directory Conventions

- `src/routes/` — one file per route, `createFileRoute`, `validateSearch` for URL state
- `src/components/ui/` — shadcn primitives only, no business logic
- `src/components/<feature>/` — feature components, under 200 lines each
- `src/server/` — `createServerFn` handlers, `db/`, `auth.ts`, `env.ts`
- `supabase/` — migrations, rollbacks, seed, functions
- `design/` — manifest and decisions for the Claude Design round trip

## Rules

1. URL state over `useState` for anything a user would bookmark or share.
2. Browser-only APIs live inside `useEffect` or `clientOnly`.
3. Secrets and database clients are reached only through `src/server/*`.
4. Every table has `tenant_id` and RLS policies per operation.
5. Every structural migration has a snapshot and a rollback file.
6. Every turn ends with `npx tsc --noEmit` exit `0` and, before deploy, `wrangler deploy --dry-run`.
7. Deploy preview first, smoke-check, then production. Never with uncommitted changes.
