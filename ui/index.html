Shell components

The parts every app sits in, built from the kit's Tailwind theme alone: one file of values, one accent set at run time, square controls, hairline rows. The text face for reading, the mono face for codes and small labels, the display face for titles.

This browser lacks CSS relative colours or the light-dark function: the accent's shades and the dark theme will not compute here. Needs Chrome or Edge 123, Safari 17.5 or Firefox 128.
