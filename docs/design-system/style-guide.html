The style guide is the UI kit

This page was the preview of a look for business apps: a blue accent, soft corners, its own table of colours. ADR-039 "one front end" (23 November 2026) replaced it. Every Brax Hub app now has one look, the hub's: the accent is the hub owner's setting, and the colours, faces and parts come from the UI kit in ui/ of this repository. An app defines none of its own.

To see the look, with every part, in light and dark and under any accent:

  1. At the repository's root: npm install, then npm run dev.
  2. Open http://localhost:4181/ for the values and the theme, and http://localhost:4181/parts.html for the parts.
  3. To see it in an app: npm ci and npm run dev in kit/example, then http://localhost:3310/modules/example/.

How an app takes the UI kit is in ui/README.md, "Taking the UI kit into an app".
